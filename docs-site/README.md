# Fairy C docs site (skeleton)

Starlight documentation site scaffold for `fairyc` (`https://0disoft.github.io/fairyc`).

## Commands

Run inside `docs-site/`:

```sh
bun install
bun run dev      # Launch local Astro dev server
bun run check    # Validate navigation, build, and root redirect
bun run build    # Build production bundle into dist/
bun run preview  # Preview production build
```
