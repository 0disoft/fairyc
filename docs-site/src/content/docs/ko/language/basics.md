Fairy C 문법은 C를 한 번이라도 구경해 봤다면 아주 친숙합니다. 세미콜론(`;`)으로 문장을 끝내고 중괄호(`{ }`)로 블록을 감쌉니다. 다만 실수하기 쉬운 부분들(초기화 누락, 암묵적 형변환, 오버플로 등)을 컴파일러가 문법 단계에서 미리 잡아 준다는 점이 다릅니다.

## 1. `let`, `var`, 그리고 `const`

변수를 만들 때는 값을 바꿀 수 있는지 여부에 따라 `let`과 `var`를 씁니다.

```c
let i32 limit = 100;      // 한 번 정하면 바꿀 수 없음
var i32 count = 0;        // 나중에 count = 1; 처럼 바꿀 수 있음
let auto_inferred = 77;   // 초기값에서 타입이 분명하면 타입 생략 가능
```

- **반드시 초기화해야 합니다**: `var i32 count;`처럼 값 없이 선언하는 문법은 없습니다. 쓰레기 값이 들어간 변수를 읽는 버그를 원천 차단하기 위해서입니다.
- **`let`은 재할당만 막습니다**: `let`으로 받은 자원(`resource`)이라도 다른 함수로 소유권을 넘기는(move) 것은 가능합니다.

모듈 맨 바깥에서 컴파일 타임 상수를 두고 싶다면 `const`를 씁니다. 아직은 `bool`, `u8`, `i32`, `u32` 스칼라 상수만 지원하며 `pub const`는 허용되지 않습니다. 순수 스칼라 도우미 함수에 `@const_eval`을 붙이면 `const`나 `static_assert(...)` 계산에도 쓸 수 있습니다.

```c
@const_eval
fn i32 square(i32 n) { return n * n; }

const i32 MAX_RETRY = square(2) + 3;
static_assert(MAX_RETRY == 7);
```

`static_assert(...)`를 적어 두면 컴파일할 때 조건이 참인지 바로 검증해 주며, 주석은 한 줄 주석 `//`, 문서 주석 `///`, 중첩 가능한 블록 주석 `/* ... */`을 지원합니다.

## 2. 기본 타입과 리터럴

Fairy C의 대표적인 기본 타입은 다음과 같습니다.

| 분류 | 타입 이름 | 설명 |
| --- | --- | --- |
| 정수(부호 있음) | `i8`, `i16`, `i32`, `i64`, `isize` | 보통 정수는 `i32`, 64비트는 `i64` |
| 정수(부호 없음) | `u8`, `u16`, `u32`, `u64`, `usize` | 바이트는 `u8`, 인덱스·길이는 `usize` |
| 참/거짓 | `bool` | `true`, `false` (정수와 섞을 수 없음) |
| 부동소수점 | `f32`, `f64` | `@repr(C)` 구조체/전달 등 제한된 경로에서 사용 |
| C ABI 타입 | `c::int`, `c::uint`, `c::size_t` 등 | C 함수(`extern C`)와 연결할 때 사용 |
| 문자열·바이트 뷰 | `ref str`, `ref CStr`, `ref u8[]` | UTF-8 문자열, C 문자열, 바이트 슬라이스 |

숫자와 문자열 리터럴에는 이런 편리한 표기법도 있습니다.

```c
let i32 million = 1_000_000;     // 밑줄(_)로 자릿수 구분 가능
let u32 mask = 0xff_00_aa;       // 16진수(0x)
let u8 bits = 0b1010_0101;       // 2진수(0b)

let ref str text = "안녕 Fairy"; // UTF-8 문자열 뷰
let ref u8[] raw = b"PK\x03\x04";// 바이트 슬라이스 리터럴
let ref CStr title = c"Window";  // 끝에 \0가 붙은 C 문자열
```

참고로 현재 Stage 0에서는 `'a'` 같은 문자(char) 리터럴이나 `10u32` 같은 숫자 접미사는 없으며, 문맥에 맞는 타입이나 명시적 변수 타입으로 맞춥니다.

## 3. 연산자와 오버플로 검사

사칙연산(`+`, `-`, `*`, `/`, `%`), 비트 연산(`~`, `&`, `|`, `^`, `<<`, `>>`), 복합 대입(`+=`, `-=`, `*=`, `/=`, `%=`, `<<=`, `>>=`, `&=`, `^=`, `|=`)을 모두 쓸 수 있습니다. (단, C의 `i++` / `i--` 나 삼항 연산자 `? :` 는 없습니다.)

중요한 안전장치가 하나 있습니다.

```c
var u8 x = 250;
x += 10; // C처럼 조용히 4로 넘어가지 않고 실행이 중단(trap)됩니다!
```

- **산술 오버플로·0 나눗셈 방지**: `+`, `-`, `*`, `/`, `%`와 시프트 범위를 벗어난 연산은 조용히 이상한 값으로 넘기지 않고 실행을 즉시 멈춥니다(trap).
- **비교 연산자 연쇄 금지**: `0 < x < 10`처럼 쓰면 컴파일 에러(`E0009`)가 납니다. `(0 < x) && (x < 10)`처럼 명확히 나누어 적어야 합니다.
- **`bool`만 조건식에 사용**: `if (count)`처럼 정수를 참/거짓으로 자동 취급하지 않습니다. 반드시 `if (count != 0)`처럼 비교식을 써야 합니다.

## 4. 명시적 형변환 (`as`)

서로 다른 타입끼리는 `+`나 `==`를 바로 할 수 없고, 값이 손실되지 않는 안전 변환은 `as`로 직접 맞추어 줍니다.

```c
let u8 byte_val = 40;
let i32 a = byte_val as i32;      // u8 -> i32 (가능)
let u32 b = byte_val as u32;      // u8 -> u32 (가능)
let usize c = b as usize;         // u32 -> usize (가능)
```

현재 안전한 `as` 정수는 값이 절대 잘리지 않는 조합(`u8 -> i32/u32/usize`, `u32 -> usize`, 그리고 32비트 환경에서의 `i32 <-> c::int`) 위주로 열려 있고, 크기를 줄이거나 부호가 바뀌는 변환은 `std::num`의 검사 함수를 통해 안전하게 처리하는 방식을 씁니다.
