如果你接触过 C 语言，Fairy C 的语法会让你感到非常亲切：语句以 `;` 结尾，代码块使用 `{ }`。不同之处在于，编译器会在程序运行前帮你拦住常见的隐患——例如未初始化的变量、静默整数溢出以及意外的隐式类型转换。

## 1. `let`、`var` 与 `const`

对于不会重新赋值的绑定使用 `let`，对于可变变量使用 `var`。

```c
let i32 limit = 100;      // 之后不能重新赋值
var i32 count = 0;        // 可以通过 count = 1; 更新
let auto_inferred = 77;   // 当值类型明确时可省略类型注解
```

- <strong>必须初始化</strong>：不允许写出没有初始值的 `var i32 count;`，从而从源头上消除读取未初始化数据的 bug。
- <strong>`let` 仅锁定重新绑定</strong>：即使某个 `resource` 是用 `let` 绑定的，你依然可以将其所有权转移（移动）给另一个函数。

对于模块级的编译期常量，请使用 `const`（目前支持类型为 `bool`、`u8`、`i32` 或 `u32` 的私有标量常量）。使用 `@const_eval` 标注的纯标量辅助函数也可以直接用于 `const` 和 `static_assert(...)` 计算：

```c
@const_eval
fn i32 square(i32 n) { return n * n; }

const i32 MAX_RETRY = square(2) + 3;
static_assert(MAX_RETRY == 7);
```

`static_assert(...)` 会在编译期间检查纯编译期条件是否成立；注释支持单行 `//`、文档注释 `///` 以及可嵌套的块注释 `/* ... */`。

## 2. 核心类型与字面量

| 类别 | 类型名 | 说明 |
| --- | --- | --- |
| 有符号整数 | `i8`, `i16`, `i32`, `i64`, `isize` | 通用整数常用 `i32`，64 位整数用 `i64` |
| 无符号整数 | `u8`, `u16`, `u32`, `u64`, `usize` | 字节用 `u8`，数组索引和长度用 `usize` |
| 布尔值 | `bool` | `true`、`false`（绝不与整数混用） |
| 浮点数 | `f32`, `f64` | 用于 `@repr(C)` 字段等受限的数据传输支持 |
| C ABI 标量 | `c::int`, `c::uint`, `c::size_t`, ... | 在绑定 `extern C` 函数时使用 |
| 文本与字节视图 | `ref str`, `ref CStr`, `ref u8[]` | UTF-8 字符串、以 NUL 结尾的 C 字符串、字节切片 |

字面量支持数字分隔符（`_`）、十六进制（`0x`）、二进制（`0b`），以及三种字符串/字节形式：

```c
let i32 million = 1_000_000;
let u32 mask = 0xff_00_aa;
let u8 bits = 0b1010_0101;

let ref str text = "Hello Fairy"; // UTF-8 字符串视图
let ref u8[] raw = b"PK\x03\x04";  // 字节切片字面量
let ref CStr title = c"Window";   // 以 NUL 结尾的 C 字符串视图
```

请注意，Stage 0 目前不支持字符字面量（`'a'`）或数字后缀（`10u32`）。字面量的类型由显式注解或上下文期望类型决定。

## 3. 运算符与受检算术

内置了标准的算术运算符（`+`、`-`、`*`、`/`、`%`）、位运算符（`~`、`&`、`|`、`^`、`<<`、`>>`）以及复合赋值运算符（`+=`、`-=`、`*=`、`/=`、`%=`、`<<=`、`>>=`、`&=`、`^=`、`|=`）。（不支持 `++`、`--` 和 `? :`。）

一条关键的安全规则：

```c
var u8 x = 250;
x += 10; // 不像 C 语言那样静默回绕成 4，而是立即触发运行时陷阱！
```

- <strong>溢出与除以零会触发陷阱</strong>：算术溢出、无符号下溢、除以零以及越界移位都会安全地中止执行，而不会破坏数值。
- <strong>不支持链式比较</strong>：请写成 `(0 < x) && (x < 10)`，而不是 `0 < x < 10`（会报 `E0009`）。
- <strong>条件必须是 `bool`</strong>：不能直接写 `if (count)`；必须写成显式比较，例如 `if (count != 0)`。

## 4. 显式类型转换（`as`）

不同的整数类型绝不会隐式混用。对于保值的宽化转换，请使用 `as` 显式转换：

```c
let u8 byte_val = 40;
let i32 a = byte_val as i32;      // u8 -> i32
let u32 b = byte_val as u32;      // u8 -> u32
let usize c = b as usize;         // u32 -> usize
```

目前安全的 `as` 转换涵盖不会丢失数据的宽化组合（`u8 -> i32/u32/usize`、`u32 -> usize`，以及在 32 位 `c::int` 目标平台上的 `i32 <-> c::int`）。窄化或改变符号位的转换，请使用 `std::num` 中提供的显式可失败辅助函数。
