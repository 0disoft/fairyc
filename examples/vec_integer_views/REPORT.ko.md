# 정수 Vec 뷰와 순회 결과

SDK stage0.83을 기반으로 i32/u32/usize 타입의 공유 및 가변 Vec 뷰와 `for-in` 순회 기능을 구현했습니다.
고정 배열과 Vec 모두 동일한 순회 규칙을 적용받습니다. 뷰를 생성할 때 추가 메모리 할당이나 원소 복사 없이
초기화된 영역만 안전하게 대여하며, 매 반복마다 요소를 직접 참조하므로 앞선 순회에서 발생한 변경이 다음 반복에도 정확히 반영됩니다.

Windows MSVC 환경에서 기본(low) 및 릴리스(release) 빌드로 총 44회의 실행 검증, 102건의 대여 오류 처리 테스트,
공개 CLI 5회 실행, 그리고 갱신된 컴파일러 기반의 기존 u8/i64 예제 4회 실행을 모두 성공적으로 통과했습니다.
신규 추가된 3종 타입에 대해 공유·가변 양측에서 각각 12건의 storage-transfer MIR 변조를 컴파일 단계에서 정상 차단했으며,
일반 및 쿼리 전용 경로에서의 비공개 전송(private transfer)도 안전하게 거부하도록 했습니다.
고정 배열 순회의 경우 MIR 코덱 왕복 직렬화 및 인터프리터 환경에서 누적 합산, continue, break, 쓰기 실행 순서의 정합성을 검증했습니다.
AST, SDK, 제네릭 기반 구조, semantic, C backend, module interface, snapshot, artifact, body hash 관련 패키지 테스트와
컴파일러 단위 테스트, 그리고 `go vet` 검사를 모두 통과했습니다.

공개 SDK 인터페이스, 스냅샷 및 함수/본문 식별자의 슬라이스 직렬화 기능을 확장하여 뷰의 원소 타입을 정확히 보존합니다.
지역 소유자 범위를 벗어나는 스코프 탈출(escape), 공유 저장소 쓰기, 가변 부모·형제 간 충돌,
순회 중 구조 변경이나 치환(replace), 이동(move), 부수 효과가 있는 경계식, 그리고 조기 반환 시의 move 동작을 엄격히 차단했습니다.
또한 경계값, 빈 구간, 인덱스 범위 초과 오류 및 순회 중 발생하는 산술 오버플로/언더플로 트랩을 종합적으로 점검했습니다.

소스 코드, SDK, 컴파일러 및 실행 바이너리 해시, CLI 실행 인수와 세부 실행 로그는
[검증 기록](../../docs/ops/evidence/vec-integer-views-20261004.json)에 기록되어 있습니다.
Linux 환경에서의 네이티브 실행 검증은 추후 일괄 진행할 예정입니다.
