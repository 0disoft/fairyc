# i64 CSV 집계 검증

기존 03-csv-aggregator 원본 및 실행 증적을 보존한 상태로, 저장소 내에
독립 예제를 추가했습니다. 숫자 파서의 반환값, 누적 합계, 최솟값·최댓값 처리를
`i64`로 확장하였으며, CSV 파싱과 숫자 연산은 Fairy C로 직접 수행합니다.

`i64` 최솟값(-2^63)까지 오버플로 없이 파싱할 수 있도록 음수 누적 방식을 적용했습니다.
곱셈·뺄셈 연산 전에 범위를 검사하고, 누적 합계를 더하기 전에도 허용 범위를 사전 점검합니다.
SDK stage0.73의 `append_i64`와 `write_bytes`를 사용하여 극단 경계값도 오차 없이 정확히 출력합니다.

`internal/cli/i64_csv_test.go`의 테스트 케이스 15개를 Windows AMD64 MSVC 환경의
기본(low) 및 최적화(optimized) 프로필에서 각각 실행하여 검증했습니다.
stdout, stderr 출력 전체와 프로세스 종료 코드를 확인하며, 비정상 입력 시 stdout이 비어 있는지도 점검합니다.

| 사례 | 요구 결과 |
| --- | --- |
| i32 최댓값 두 개 | 합계 4294967294 |
| 양수·음수 32비트 초과 값 | 합계 10000000000 |
| i64 최솟값·최댓값·두 값의 합 | 정상 출력, 두 값의 합은 -1 |
| 부호 있는 0·긴 선행 0 | 0 |
| 따옴표·공백·두 번째 열 | 합계 0 |
| 최댓값 + 1·최솟값 - 1·긴 숫자 | 입력 범위 오류, 종료 코드 1 |
| 양수·음수 합계 초과·후반 합계 초과 | 합계 오류, 종료 코드 1 |
| 소수·빈 숫자 | 문법 및 빈 값 오류, 종료 코드 1 |

실행 원시 결과, 입력·소스 및 생성된 실행 파일(EXE)의 SHA256 해시는
[검증 기록](../../docs/ops/evidence/i64-csv-20261001.json)에서 확인할 수 있습니다.

큰 정수 리터럴이 이항 연산 좌변에 올 때 우변 타입을 추론하지 못하는 제약은
현재 유지되고 있습니다. 이에 따라 합계 범위 검사는 명시적 `i64` 변수를 사용하도록 작성했습니다.
참조 재대여(reborrow), 가변 슬라이스 서브뷰, 배열 반복 초기화, 좌변 리터럴 추론 등은
추후 별도 작업으로 진행될 예정입니다.
