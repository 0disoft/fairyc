# Report assets

- `fairyc-logo.png` is a byte-for-byte copy of `assets/brand/fairyc-logo-horizontal-v1.png`
  used by the benchmark report sidebar. Keep the copy in sync when that brand asset changes.
- `icons/*.svg` are unmodified Feather 4.29.2 icons from
  <https://github.com/feathericons/feather/tree/v4.29.2/icons>, distributed under the
  adjacent `icons/LICENSE.txt` (MIT).

The renderer embeds these assets in each HTML report; exported reports need no CDN or asset server.
