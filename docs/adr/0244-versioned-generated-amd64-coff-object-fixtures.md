# ADR 0244: Versioned generated AMD64 COFF object fixtures

- Status: Implemented local fixture gate
- Date: 2026-07-31
- Fixture source: `spec/fixtures/coff-generated-object/manifest-v0.json`
- Fixture runner: `internal/pecofffixture/`
- Object generators and inspector: `internal/pecoff/`
- Depends on: ADR 0231, ADR 0241, ADR 0242, ADR 0243

## Context

The weak-external, relocation-overflow, and version-2 bigobj probes were deterministic generated
objects with unit and real-LINK evidence, but their exact generated bytes were not versioned test
data. Storing raw hexadecimal copies would duplicate generator output and would make the smallest
relocation-overflow vector consume about 1.3 MiB as text.

A digest alone would freeze bytes but would not explain which linker-visible property changed.
Structural expectations alone would permit padding, reserved fields, instruction bytes, or table
layout to drift while the parser produced the same receipt. The fixture needs both oracles.

## Decision

1. Add strict manifest `fairyc.coff-generated-object-fixtures/v0` for the three existing AMD64
   object generators. Generator identity and every ordered string input are explicit fixture data.
2. Invoke every generator twice and require byte identity before checking expectations. This makes
   determinism a direct oracle instead of an inference from a committed digest.
3. Freeze the complete object with exact byte length and lowercase SHA-256. Do not store a second
   raw or hexadecimal copy of the generated bytes.
4. Reparse the generated object through `InspectObject` and require exact machine, file
   characteristics, ordinary-versus-bigobj identity, bigobj version, sections, and every primary
   symbol. Weak symbols also freeze fallback table index, fallback name, and search characteristic.
5. Represent relocations as ordered contiguous runs. Runs must start at zero, contain at least one
   record, have no gaps or overlap, remain in range, and partition the complete parsed relocation
   sequence. Every record in a run must match its section, address, target index and name, and type.
   This covers all 65,535 semantic overflow relocations without listing 65,534 identical entries.
6. Keep the existing raw-object v0 fixture independent. It remains the parser's small hand-owned
   ANY and associative-COMDAT corpus; the generated fixture owns generator byte compatibility.

## Evidence and limits

The manifest freezes a 250-byte SEARCH_ALIAS object, a 655,471-byte extended-relocation object,
and a 161-byte version-2 bigobj. Tests kill generator identity and arity, digest format, byte length,
symbol expectations, relocation partitioning, unknown fields, trailing JSON, and representative
missing required fields. Existing object tests remain responsible for malformed wire encodings;
existing Windows smoke remains responsible for MSVC map ownership, final relocation formulas, and
native result 42 at low and optimized profiles.

This contract versions compiler-private test generators, not Fairy C output stability or a public
object ABI. Raw stored copies remain intentionally absent. Weak NOLIBRARY and LIBRARY search modes,
high-section bigobj, bigobj auxiliaries and COMDAT, bigobj relocation overflow, another producer or
linker, and hosted same-commit evidence remain separate gates.
