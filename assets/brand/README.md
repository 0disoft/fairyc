# Fairy C brand assets

This directory contains the README logo and its source artwork. Only the files
listed as README logos below are selected for that surface; other artwork remains
a source concept unless explicitly designated for a use.

## README logo v1

- Selected by the project owner on 2026-10-20: mascot concept 1, with a horizontal
  mascot and rounded `Fairy C` wordmark.
- Intended surface: the root README, displayed at 540 CSS pixels wide.
- Default: `fairyc-logo-horizontal-v1.png`, a transparent PNG with a deep-teal wordmark.
- Dark theme: `fairyc-logo-horizontal-dark-v1.png`, a pale-mint wordmark on an
  opaque dark background. This variant is not transparent.
- Both images: 2172 x 724 pixels.
- Provenance: adapted from the owner-supplied mascot below with the built-in
  image generation tool. The selected concept was reduced to a single horizontal
  lockup; the dark variant uses light lettering for contrast.
- The README uses a `picture` element to select the dark variant when requested
  by the reader's color scheme, with the transparent logo as its fallback.

These files are README artwork, not a small-size favicon set. The original
mascot source remains unchanged. This selection records project use; it does not
assert trademark registration or grant third-party trademark rights.
